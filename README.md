# 🍻 회식 정산기

2차, 3차로 이어지는 회식에서 차수마다 참석자와 정산 방식이 달라도
사람별로 낼 금액을 계산해 주는 한 페이지 웹앱입니다.

👉 https://hoesik-calculator.vercel.app/

## 기능
- 참석자 이름 입력 (최대 10글자, 중복 이름 방지)
- 최대 3차까지 차수 추가 (차수마다 색으로 구분)
- 차수마다 총 금액 입력, 참석자 체크
- 차수마다 정산 방식 선택
  - 1/N
  - 특정인 부담 + 1/N: 부담자가 정한 금액을 내고, 나머지는 부담자를 뺀 참석자끼리 1/N
- 사람별 총 금액 표시 (100원 단위 올림) + 차수별 내역
- 올림 때문에 실제 총액보다 더 걷히는 금액 안내
- 단톡방에 붙여넣을 수 있는 결과 복사 (카카오톡 인앱 브라우저 지원)
- 정산 기록 저장, 불러오기, 삭제 (최대 20개, 이 기기의 브라우저에만 저장)
- 잘못된 입력 안내: 참석자가 없는 차수, 부담자 미선택, 부담액이 총액보다 큰 경우 등

## 계산 규칙
1. 차수마다 사람별 금액을 소수점까지 정확히 계산
2. 사람별로 모든 차수 금액을 더함
3. 합계를 100원 단위로 한 번만 올림
4. (걷는 총액 − 실제 총액)을 "더 걷히는 금액"으로 안내

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 디자인, 휴대폰 대응, 다크 모드 |
| `script.js` | 계산 로직과 버튼 동작 |

설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.
배포는 Vercel을 사용하며, GitHub `main` 브랜치에 올리면 자동으로 반영됩니다.
