# 🍻 회식 정산기

2차, 3차로 이어지는 회식에서 차수마다 참석자와 정산 방식이 달라도
사람별로 낼 금액을 계산해 주는 한 페이지 웹앱입니다.

## 기능
- 참석자 이름 입력
- 최대 3차까지 차수 추가
- 차수마다 총 금액 입력, 참석자 체크
- 차수마다 정산 방식 선택: 1/N, 또는 특정인이 일정 금액 부담 후 나머지 1/N
- 사람별 총 금액 표시
- 단톡방에 붙여넣을 수 있는 결과 복사

## 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 디자인, 휴대폰 대응 |
| `script.js` | 계산 로직과 버튼 동작 |

설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.
배포는 Vercel을 사용합니다.
